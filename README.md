# Codemate — An Expressive Coding Companion

Hi.

This is my first ever AI project.

For me, Codemate should be:

> “A living coding partner that understands your projects, remembers your habits, and actively helps you build software.”

Not just another chatbot inside an IDE.

If you somehow stumbled onto this repository randomly, just know this project is mostly an experiment.

I genuinely wanted an AI that I could actually *code with* — something that feels more present, expressive, intelligent, and collaborative than traditional coding assistants.

---

# Vision

Most AI coding tools feel transactional.

Prompt in.
Response out.

Codemate aims to feel different.

The goal is to create something that:
- understands your codebase
- remembers your workflow
- adapts to your habits
- actively assists development
- feels expressive and alive
